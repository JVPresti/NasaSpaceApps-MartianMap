# Presentation beats

The talk runs in the presentation mode on `main` (#330): https://martian-map.fernando-haro-c.workers.dev/?present=1.
Its beats live in `src/present/beats.js`; this file follows them. The table below is generated by
`node docs/pitch/tools/sync-present.mjs`: each beat's captions, chips and source line as the judges see them, with the
numbers from `public/present/plan.json`, and the line `script-en.md` says over it. Do not edit the table by hand.

> **Format.** At most 4 minutes and 5 to 6 slides (the organisers' official guidelines). Six beats, one per slide,
> 3:00 on autoplay: `open` 16 s, `stakes` 14 s, `zone` 18 s, `radiation` 12 s, `demo` 85 s, `close` 35 s. They come
> from the presentation thread's PR #373 (`feat/present-story-cut`). Until it merges, the table below is generated from
> that branch with `node docs/pitch/tools/sync-present.mjs --beats <file>`.

Autoplay is on. If the timing slips, **Right** or **Left** takes over: the first press only stops autoplay, and each
press after it moves one beat. **L** switches English and Spanish; **Esc** leaves the presentation. If WebGL fails,
the page shows "3D view unavailable. Captions only"; use `out/deck-global.pdf` instead (`demo-run-sheet.md`). The
beat after `close`, `live`, only appears with `&live=1`.
