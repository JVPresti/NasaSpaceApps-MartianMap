# 8-minute version script (English)

The English version of `script-8min-es.md`, line for line, for rehearsal. Same demo (`docs/DEMO.md`, segments 1 to 11), same numbers.

> **Confirm with the Ensenada organisers:** `docs/DEMO.md` (#282) points to an 8 minute demo, and we assumed a 5 minute pitch. This script covers the 8 minute case, with the full DEMO.md demo, 32 seconds of story before it and 39 after.

The demo is all of `docs/DEMO.md`, segments 1 to 11, with the times keiwv measured (6:40 on #282's measured run at 8ec6f72). Each segment here has a little more to say. Controls are verified in `demo-run-sheet.md`, cut C. Spanish version: `script-8min-es.md`.

**Time.** Each demo row gets the time keiwv measured for its segment on 8ec6f72, 6:40 in all. The story around it is cut to 1:10, so the table ends at 7:50.

**Thesis:** on Mars, the question isn't where you can go. It's where you can go and still get home.
